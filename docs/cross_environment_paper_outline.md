# Cross-Environment Paper Outline

## Working title

Property Fulfillment Is Not Control Utility: Prescribed Predictive-Feature Priors in Streaming RL

## Abstract

Question, strict streaming linear design, four latent geometries, property gates, heterogeneous three-seed pilot, failed E2 phase-order prior, and planned 20-seed confirmation.

## 1. Introduction

- Distinguish attractive feature geometry from useful predictive state.
- State the controlled variable: representation property, not controller or predictive questions.
- Contributions: causal benchmark, property diagnostics, cross-geometry counterexamples.

## 2. Related work

- Predictive state/GVFs and streaming RL.
- Conditioning, whitening as a second-order transform, sparsity, norm constraints.
- Structured priors for categorical, circular, product, and continuous state.

## 3. Methods

- One-pass fixed trace → linear TD predictions → transform → SARSA(lambda).
- E1-E4 and observation aliasing.
- Compact/mixed banks and fixed semantic questions.
- R0-R8 and M1-M4 definitions.
- Oracle isolation, diagnostic-only latent state, held-out grouped probes.
- Staged matrix, seeds, metrics, manifests, and remote guard.

## 4. Property fulfillment

- Synthetic and real-stream tables.
- Whitening, moments, sparsity, boundedness, simplex/block/anisotropy.
- E2: unit-radius success versus phase-order failure.

## 5. Local pilot results

- Faceted control curves and final-performance matrix.
- E3 positive signals; E1 null; E2 uncertainty; E4 negative/mixed results.
- Rank/isotropy/decodability versus performance.
- Same-budget bank and horizon ablations.

## 6. Remote full results

- Reserved: 20-seed main effects and uncertainty.
- Reserved: compact/mixed, matched/short, E1 adaptation.
- Do not fill until guarded remote batches validate completely.

## 7. Discussion

- Property fulfillment is necessary for interpretation but not sufficient for utility.
- Predictive semantics can be the bottleneck for matched geometry.
- Scale, magnitude, controller-rate interactions, and small-sample uncertainty.
- Negative results as design guidance.

## 8. Limitations and reproducibility

- Linear fixed-bank scope, four small environments, three-seed local evidence.
- Exact configs, manifests, failed batches, code/test/remote commands.
