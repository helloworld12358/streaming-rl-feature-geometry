# Cross-Environment Poster Outline

## Header

**Property fulfillment is not control utility in streaming predictive representations**

One-sentence question: do prescribed feature properties help the same strictly streaming linear RL agent across binary, circular, product, and continuous latent geometries?

## Left column: controlled experiment

- Pipeline diagram: observation → fixed trace → linear TD predictions → one transform → SARSA(lambda).
- Causality/no-replay/oracle-isolation badges.
- Four environment sketches: E1 cue, E2 circle, E3 identity × phase, E4 position/velocity.
- Compact staged matrix rather than a full Cartesian product.

## Center column: properties and verification

- Generic properties R0-R8 and matched M1-M4.
- Property pass/fail heatmap.
- Key failure callout: real E2 unit radius passes, phase order fails (`0.2406 < 0.3`).
- Small geometry panels for E1-E4.

## Right column: local pilot

- Faceted final-performance matrix with mean ± SEM, n=3.
- Main callouts: E3 positive signals; E1 null; E2 uncertain; E4 raw often best.
- Compact/mixed and horizon paired-difference mini-panels.
- Rank/isotropy are not sufficient for control.
